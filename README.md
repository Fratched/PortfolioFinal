## JavaScript Game

### Whack-a-Mushroom 🍄

The portfolio includes an interactive JavaScript game called Whack-a-Mushroom.

The objective is to click on the mushrooms when they appear before they disappear.

**Game Features:**
- 30-second countdown timer.
- Score tracking.
- Best score saved using localStorage.
- Three lives per game.
- Random mushroom appearances.
- Start, pause, resume, and restart buttons.
- Win condition of reaching 15 points.

The game demonstrates JavaScript concepts such as variables, functions, conditions, event listeners, timers, and DOM manipulation.
